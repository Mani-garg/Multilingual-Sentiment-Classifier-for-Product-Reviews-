# ONNX Export and Optimization Guide

## 1. Export Architecture

Exporting deep learning models to **Open Neural Network Exchange (ONNX)** decouples model inference from heavy training frameworks (TensorFlow, PyTorch) and provides optimized native runtime execution across CPU and GPU hardware.

### Dynamic Axis Declaration
In sentiment classification, input reviews vary dramatically in length, and production traffic varies in batch size. The exported ONNX graph explicitly defines dynamic dimensions:
- `input_ids`: `{0: "batch_size", 1: "sequence_length"}`
- `attention_mask`: `{0: "batch_size", 1: "sequence_length"}`
- `logits`: `{0: "batch_size"}`

---

## 2. Dynamic INT8 Quantization

The optimization pipeline utilizes `onnxruntime.quantization.quantize_dynamic` targeting `QuantType.QInt8`:
- Weights are quantized from 32-bit floating point (`float32`) to signed 8-bit integers (`int8`).
- Activations are quantized dynamically at runtime based on the dynamic range of incoming inputs.
- Benefits:
  - **Memory Footprint**: ~3x to 4x reduction in model size on disk and in RAM.
  - **Cache Locality**: Smaller tensor representations reduce L1/L2/L3 cache misses during CPU matrix multiplication.
  - **Inference Speedup**: Vectorized integer arithmetic (AVX-512 VNNI / AVX2 / ARM NEON) accelerates matrix multiplications.

---

## 3. Numerical Parity Validation

Before promoting a quantized ONNX model to serving, the pipeline enforces **strict parity checks**:
- Runs identical sample batches through FP32 ONNX and INT8 quantized ONNX.
- Asserts that argmax class predictions match in $\ge 99.0\%$ of cases.
- Validates that absolute probability score drift stays within acceptable bounds:
  $$\max |\hat{p}_{\text{fp32}} - \hat{p}_{\text{int8}}| < \epsilon \quad (\epsilon = 0.05)$$

---

## 4. Optimization Report Artifact

Optimization metrics are generated by `scripts/export_onnx.py` and saved to `artifacts/reports/onnx_optimization_report.json`:
- Disk artifact size before and after.
- p50, p95, and p99 inference latencies.
- Throughput speedup ratio.
